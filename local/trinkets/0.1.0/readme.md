# `trinkets.typ` &ndash; набор "бирюлек" для [Typst](https://typst.app/)

| Файл       | Содержимое                                     |
| -----      | -----                                          |
| `math.typ` | Собственные математические операторы и символы |
| `func.typ` | Вспомогательные функции                        |

В пакете переопределяются некоторые символы:
- `<=` вместо `sym.lt.eq` ($\leq$) преобразуется в `sym.lt.eq.slant` ($\leqslant$),
- `>=` вместо `sym.gt.eq` ($\geq$) преобразуется в `sym.gt.eq.slant` ($\geqslant$).

Так как эти преобразования проводятся через правило `show <smth>`, то они действуют только до конца блока или файла (то есть в нашем случае `math.typ`, в котором эти преобразования и определены).
Поэтому пришлось написать примитивную функцию `trinkets`, которая принимает на вход что-либо, оборачивает это в блок кода, в котором также применяются `show`-правила.
```typst
show: trinkets
```
